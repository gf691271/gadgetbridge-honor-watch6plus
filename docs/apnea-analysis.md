# 夜间心率变异性分析：CVHR 与自主神经激活

> 数据：2026-11-09 夜间，HONOR Watch 6 Plus
> 方法：Hayano ACAT（CVHR）+ Lachapelle/Adachi 心率骤升判据
> **定位：探索性指标，不是诊断，不输出 AHI**

---

## 0. 一句话结论

**这一夜没有显示出明显的周期性心率波动，也没有频繁的自主神经激活。**

| 指标 | 本夜 | 文献阈值 | 判读 |
|---|---|---|---|
| Fcv（ACAT 严格） | **0 /h** | ≥11/h | 远低于阈值 |
| Fcv（ACAT 宽松） | 2.3 /h | ≥11/h | 远低于阈值 |
| 心率骤升（≥6 bpm） | **8 /h** | ≥40/h 为"频繁" | 远低于阈值 |

两套独立判据给出一致方向。但**单夜、无 PSG、无血氧**，不能反推"没有呼吸暂停"。

## 2. 方法

### 2.1 ACAT / Fcv（Hayano et al. 2020, PLoS ONE）

参照原文 Methods：

```
1. 有效 NN：400–1400 ms 且 |NN − 局部均值| / 局部均值 < 20%
2. 平滑：20 s 滑动窗二阶多项式
3. 谷检测：宽度 10–120 s，深度/宽度 > 0.7 ms/s
4. 包络：130 s 窗内 95/5 百分位
5. 判据：
   a. 相对谷深 > 包络范围的 40%
   b. 相邻谷周期 25–130 s
   c. 与前后各 2 个谷的形态相关均值 > 0.4
   d. 连续 3 周期满足 (3−2l1/s)(3−2l2/s)(3−2l3/s) > 0.8，s = 平均周期
6. Fcv = 合格谷数 / 有效小时
```

实现：`tools/acat_fcv.py`

### 2.2 心率骤升（autonomic activation）

```
基线：前 60 s 中位心率
阈值：60 s 内升高 ≥ 6 bpm（Lachapelle 2022、Adachi 2003 的 PRRI-6）
随后：120 s 内回落 ≥ 3 bpm
分箱：10 s
```

实现：`tools/detect_surges.py`

## 3. 结果

### 3.1 ACAT

```

候选谷 1111 个
通过 (a)(b)(c) 的：12 个  → Fcv = 2.3 /h
再通过 (d) 连续周期性规则的：0 个  → Fcv = 0 /h
```

那 12 个候选谷的时间点（宽松口径）：

```
03:29  03:40  04:26  04:55  04:59  05:14
05:14  05:36  06:52  06:55  07:39  07:45
```

### 3.2 心率骤升

```
48 次 / 6.02 h ≈ 8.0 /h
```

典型事件（幅度最大的几次）：

```
03:28  62 → 76 bpm  (+14)
```

## 4. 怎么读这个结果

### 4.1 可以说的

- 这一夜的 CVHR 负荷 **远低于** Hayano 队列中 AHI≥15 的典型水平（Fcv 中位数约 17/h）；
- 自主神经激活约 8 次/小时，**远低于**"频繁觉醒"的 40/h 判据；
- 05:00 附近有一簇事件，可能是体位改变、REM 期或环境干扰。

### 4.2 不能说的

| 不能说的 | 原因 |
|---|---|
| "没有睡眠呼吸暂停" | 单夜、无 PSG、无血氧；hypopnea 无法定义 |
| "AHI = x" | 我们没有气流/血氧/EEG |
| "这些是微觉醒" | AASM 觉醒必须 EEG；只能叫自主神经激活 |
| "Fcv=0 说明算法没问题" | 也可能算法对腕表 PPG 不够敏感 |

### 4.3 已知假阳性来源（本夜未排除）

- **周期性腿动（PLM）**：Hayano 2011 明确指出这是主要干扰源；
- **肢体运动/翻身**：会产生类似的 HR 骤升；
- **REM 期**：本身就交感张力高；
- **室早**：会让 RR 出现大停顿（本夜 ectopic 率未单独统计）。

## 5. 与文献的定位

| 论文 | 数据 | 结论 | 对我们的意义 |
|---|---|---|---|
| Hayano 2020, PLoS ONE | 41 例 PSG + 腕表 PI | Fcv≥11/h → AHI≥15，sens 82% / spec 89% | 方法可用，但我们缺 PSG 校准 |
| Hayano 2011, Circ AE | 862 例 ECG | AUC 0.913；PLM 是主要假阳性 | 提醒我们 PLM 干扰 |
| Lachapelle 2022 | 82 例 | 心率升 ≥6 bpm 定义 autonomic hypopnea | 我们用这个阈值 |
| Adachi 2003 | 33 例 | PRRI-6，cutoff 40/h，sens 0.88 / spec 0.86 | 我们用这个做"频繁"判据 |
| Olsen 2018 | 258 例 ECG | ECG-only 觉醒检测 precision 0.72 / sens 0.63 | 纯心率做觉醒的天花板 |
| Samsung（FDA cleared） | 152 例 | sens 94% / **spec 67%** | 消费级上限 |

**关键**：Hayano 的 82/89 是**受试者级筛查**，且必须用同步 PSG 定阈值。我们没有 PSG，所以只能报指标，不能报准确率。

## 6. 下一步

| 优先级 | 事项 | 目的 |
|---|---|---|
| 1 | **多夜重复**（3–7 晚） | 看 Fcv 的夜间变异；单夜不可靠 |
| 2 | 补血氧 | 若能拿到 SpO2，hypopnea 才有可能定义 |
| 3 | 与体动对齐 | 把 HR 骤升与 ACC 事件对照，扣掉运动伪迹 |
| 4 | 与录音对齐 | 鼾声段落 vs HR 骤升，这是最有信息量的交叉验证 |
| 5 | 若认真做研究 | 20–30 例同步 PSG，前 15 例定阈值、后 15 例测试 |
